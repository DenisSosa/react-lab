
✨ Feature: Listar usuarios

Este PR agrega la funcionalidad de listar usuarios en la aplicación React.

Cambios principales:

🆕 Creación del componente UserList para mostrar la lista de usuarios.

🌐 Consumo de API: https://jsonplaceholder.typicode.com/users usando fetch.

⚡ Manejo de estados de carga y error.

🎨 Estilos básicos con CSS para mejorar la presentación de la lista.

Notas:

Parte de la práctica de React sobre consumo de APIs y renderizado de listas.

Todos los cambios fueron probados localmente y la lista se renderiza correctamente.
